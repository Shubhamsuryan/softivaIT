# Feature Report for Softiva IT Project

## Project Overview
This project is a comprehensive React-based website for Softiva IT, a company specializing in Intelligent Document Processing (IDP) solutions. The website serves as a marketing and informational platform showcasing the company's services, products, expertise, and resources related to document processing technologies.

## Technology Stack
- **Frontend Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Deployment**: Static site generation via Vite
